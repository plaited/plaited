# @plaited/pi-dev

pi plugin for general coding-agent usage in [pi](https://github.com/earendil-works/pi-coding-agent).

Depends on [`plaited`](../plaited) (`workspace:*`). Provides agent-facing
utilities, skills, and tooling for everyday coding work in pi — the general-purpose
complement to [`@plaited/pi-assemble`](../pi-assemble) (which targets MCP App
development).

## Development

```bash
bun run check    # biome + tsc
bun test
```
